# New Zealand Bus & Train Fleet Database — v2

A New Zealand-focused fleet research website.

## Included
- Searchable fleet database
- Category filtering
- NZ-specific vehicle-type image cards
- Fleet numbers and special research records
- Mobile-friendly layout
- Custom-domain configuration for `nzbustrainfleetdatabase.co.nz`

## Important
The website is configured for the domain, but registering the domain itself is a separate step and cannot be completed by the website files. Check/register the domain through an accredited .nz registrar, then point it at your chosen free static host.

Some visual reference cards link to external NZ transport/photo sources rather than copying their photographs into this package. Check the relevant source's image terms before republishing images.

## Free hosting
The package is suitable for GitHub Pages, Cloudflare Pages, Netlify, or another static host.

For GitHub Pages, the included `CNAME` file tells GitHub the custom domain to use.
